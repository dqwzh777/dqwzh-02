# 00-Inbox 收件箱

这里是所有新资料的第一入口。

以后还没有分类、还没有判断价值、还没有决定放到哪里的信息，先放进这里。包括：

- 临时想法
- 录音转写
- 聊天记录整理
- 截图说明
- 网页摘录
- 文件说明
- 待整理素材
- 我帮你新生成但还没归档的内容

## 使用原则

先收进来，不急着分类。

每天或每隔几天，再把这里的内容整理到对应位置：

## 整理口令

你以后可以直接说：

- 帮我整理今天的收件箱
- 把收件箱里的内容分类
- 看看收件箱里哪些值得留下
- 把收件箱里的内容放进知识库
