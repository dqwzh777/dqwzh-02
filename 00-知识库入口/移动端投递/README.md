# 移动端投递

本目录只在 `windows-inbox` 分支使用，**不要直接向 `main` 提交移动端临时资料**。

## 使用规则

1. 在 Windows PowerShell 运行 `./00-知识库入口/移动端投递/移动端同步.ps1 主库`，安全更新并浏览主库。
2. 要写入资料时，运行 `./00-知识库入口/移动端投递/移动端同步.ps1 投递`。
3. 将临时任务、信息或文件放进本目录；文件名加日期和用途，例如 `2026-08-23-客户访谈录音.m4a`。
4. 完成后运行 `./00-知识库入口/移动端投递/移动端同步.ps1 发布`；它只提交本目录并推送 `windows-inbox`，不会写入 `main`。
5. 不要提交 `.obsidian`、知识库导航、系统脚本或其他目录。
6. macOS 主机每天收件时会只读拉取此分支，把支持格式复制到 `知识库投递/Windows移动端`，然后沿用原有去重、提取、OCR/转写和待整理流程。
7. 成功被收件不等于已验证知识；后续仍在 [[00-知识库入口/待整理资料|待整理资料]] 完成人工确认和分流。

## 安全边界

- 不投递密码、令牌、Cookie、验证码、私钥或其他机密。
- 视频和超过 100MB 的文件只登记链接或说明，不直接上传。
- 主机读取本分支时不会自动合并该分支到 `main`；失败只会写入运行报告，不会阻断主机其他收件。
