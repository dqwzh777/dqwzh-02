# 自身竞争力洞察模板

📌 来源：作业四_判断力的建立.docx  
🎯 应用：讲清楚你有什么别人没有，以及凭什么是你来说这件事

---

## 要写清楚的三件事

### 1. 一句话主张

给完全外行的人讲清楚：你是做什么的，解决什么问题，服务谁。不能超过 30 字。

| 字段      | 内容  |     |
| ------- | --- | --- |
| 我是做什么的  |     |     |
| 我解决什么问题 |     |     |
| 我服务谁    |     |     |
| 一句话主张   |     |     |

---

### 2. 最硬的差异化

可以来自数据 / 报告 / 案例 / 资质 / 专利。要具体、可比较，不要只写「更好」「更专业」。

| 字段 | 内容 |
| --- | --- |
| 差异化证据 |  |
| 可量化指标 |  |
| 对比对象 |  |
| 为什么可信 |  |

---

### 3. 最打动人的故事

写一个真实场景，可以是成功的，也可以是失败的。失败故事往往更有说服力。越具体越好。

| 字段 | 内容 |
| --- | --- |
| 故事发生的场景 |  |
| 当时的问题 / 冲突 |  |
| 我做了什么判断 |  |
| 后来发生了什么 |  |
| 这个故事说明我有什么能力 |  |

---

## 知识库自我介绍

把「一句话主张 + 最硬的差异化 + 最打动人的故事」合并成第一人称介绍。

判断标准：

- 看完觉得「像我说的，可以用」→ 合格
- 看完觉得「不太对」→ 回头补具体信息

```markdown
我是……

我主要帮助……

和别人不一样的是……

我之所以能讲这件事，是因为……

有一个真实经历是……
```
