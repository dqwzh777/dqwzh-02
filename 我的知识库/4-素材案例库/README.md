# 4-素材案例库

> 装什么：老板故事、客户案例、失败经验、真实对话、行业金句
> 谁会读：几乎所有内容生产 skill——内容有人味的关键
> 真实场景：「让内容真不真,就看这一库够不够厚」

---

## 推荐文件结构

```
4-素材案例库/
├── README.md（本文件）
├── 老板故事.md              ← 你自己的经历、转折、踩坑
├── 客户案例.md              ← 服务过的客户成长 / 失败案例
├── 失败经验.md              ← 自己创业 / 业务里的踩坑
├── 真实对话.md              ← 跟客户 / 同行 / 学员的精彩对话片段
└── 行业金句.md              ← 行业大佬 / 同行 / 学员说过的金句
```

## 每条素材建议格式

```markdown
## [素材标题]

📌 来源：[YYYY-MM-DD,场景说明]
🎯 应用：[未来用在哪——可留空待补]

[素材正文,保留原话]

#标签 #分类
```

## 标签建议

按主题打标签,以后 AI 能精准调用：

- `#个人故事` `#客户案例` `#失败经验`
- `#情绪激发` `#决策卡点` `#转折时刻`
- `#具体数字` `#真实细节`

---

## 上手第一步

写 **3 个老板故事**和 **3 个客户案例**——优先挑"有具体数字、有真实细节、有情绪转折"的。

这是写出有人味内容的根。
