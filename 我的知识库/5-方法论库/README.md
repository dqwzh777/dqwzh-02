## 上手第一条铁律

**按主题分,不按来源分。**

- 错：按「《XX 书》笔记 / RAY 公众号笔记 / 富贵线下课笔记」分类
- 对：按「营销与销售 / 内容创作 / 运营策略」分类

理由：你写销售文案时,AI 要的是"所有跟销售相关的方法论"——不管它来自哪本书、哪个老师。

**来源是过去式,应用才是未来式。**

## 每篇方法论建议格式

```markdown
# [方法论名称]

📌 来源：[书名+章节 / 课程+老师 / 自己原创]
🎯 应用：[未来在哪个场景调用——可留空待补]

## 核心论点

[用自己的话写,不要复制粘贴原文]

## 怎么操作

1. 
2. 
3. 

## 真实案例

[举一个自己用过 / 见过的案例]
```

## 上手第一步

**不用主动填**——把「录音处理」skill 跑起来,以后每段录音里出现的方法论,AI 会自动入库。

如果手痒想先填,就把你最常用的**一条获客方法**写下来,放在 `营销与销售/` 下。
