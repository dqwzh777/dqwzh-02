# 7-判断力库

> 装什么：用户差评里的真实痛点、竞品忽略的机会、自身竞争力证据、由此沉淀出的判断逻辑
> 谁会读：战略诊断、产品定位、小红书选题、公众号文章、口播脚本、销售话术相关 skill
> 真实场景：「遇到一个市场信号时，我应该怎么判断、怎么表达、怎么切入」

---

## 判断力从哪里来

判断力不是凭空来的，它来自三个方向的信息汇合：

| 信息来源 | 告诉你什么 | 产出的判断 |
| --- | --- | --- |
| 差评（用户声音） | 市场在骂什么；真正未被满足的需求是什么 | 遇到高频痛点时的决策逻辑 |
| 竞品（对手视角） | 对手在说什么；忽略了什么；用户为什么选他 | 差异化切入话术；流量链路判断 |
| 自身（内部沉淀） | 你有什么别人没有；凭什么是你说这件事 | 知识库自我介绍；一句话主张 |

## 完成标准

- 差评聚类：Top 3 高频主题 + 3 条判断逻辑，格式为「遇到 X → 判断是 Y」
- 竞品拆解：3 个竞品 x 4 个维度 + 1 条差异化话术
- 自身竞争力：一句话主张 + 差异化指标 + 真实故事 + 知识库自我介绍

## 上手第一步

先从 `差评聚类/差评聚类模板.md` 开始，收集至少 30 条差评关键句。真正值钱的不是所有差评，而是「买了但没解决问题」「和描述不符」「不知道怎么用」这类真实痛点。
