# 平台接入与 AI 专家团的证据分层方法

## 平台自动导入九层

把“能不能自动导入”拆成九个独立验收层：来源授权、拉取或回调、字段映射、平台 ID 幂等去重、项目/负责人路由、失败重试、导入对账、审计留痕、人工兜底。官方 API 或授权连接优先；RPA 只适合小规模 POC，人工导出上传是稳定兜底。任何一层未验证，都不能写成长期稳定能力。

## 专家团角色边界

WorkBuddy 专家团中的主理人是 lead agent，负责确认任务、拆解、调度成员 Agent 并汇总结果，不等同于真人专家。项目人工负责人、成员 Agent、知识来源、工具权限和专业复核责任应分别说明，辅助分析不能直接表述为正式专业意见。

## 证据记录

对第三方工具或平台保持“事实—推断—未验证”分层。二进制样本可做静态字符串和资源审查，但不安装、不运行、不连接真实账号；静态证据不能替代授权后的运行时验收。
