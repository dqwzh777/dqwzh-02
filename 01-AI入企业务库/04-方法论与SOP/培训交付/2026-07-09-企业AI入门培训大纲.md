# 企业 AI 入门培训大纲

适合场景：第一次给企业内部员工做 AI 使用培训  
建议时长：3 小时  
主力工具：ChatGPT  
备用工具：Kimi、豆包  
培训目标：让学员完成安装登录，并能用 AI 处理一个真实工作任务

---

## 一、培训前准备

### 讲师提前准备

1. 提前打开 ChatGPT，并确认能正常使用。
2. 同时打开 Kimi 和豆包备用页面。
3. 准备一个演示账号，防止现场登录失败。
4. 准备一个不含敏感信息的测试文档，用于演示上传和总结。
5. 提前把工具链接发到培训群。

### 发给学员的通知

```
各位同事，明天 AI 入门培训会统一使用 ChatGPT。

请提前准备：
1. 一台可联网电脑
2. 一个可用邮箱或已有 ChatGPT 账号
3. 确认电脑可以正常打开浏览器

ChatGPT 官方地址：
https://chatgpt.com/download/

备用工具：
Kimi：https://www.kimi.com/zh
豆包：https://www.doubao.com/download/desktop

如果提前安装不了也没关系，明天会现场带大家一步一步完成。
```

## 二、3 小时培训大纲

| 时间 | 模块 | 你要讲什么 | 学员要做什么 |
|---|---|---|---|
| 0-10 分钟 | 开场 | 说明今天不是讲技术，而是教大家把 AI 用到工作里 | 听清楚目标 |
| 10-20 分钟 | 工具策略 | ChatGPT 是主力，Kimi/豆包是备用，工具卡住不影响学习 | 知道卡住时怎么切换 |
| 20-45 分钟 | 安装登录 | 带大家打开官网、安装或使用网页版、登录账号 | 完成登录 |
| 45-60 分钟 | 第一次提问 | 带大家问出第一条问题，并继续追问一次 | 每人成功得到 AI 回答 |
| 60-85 分钟 | 提问方法 | 讲“角色 + 背景 + 目标 + 要求 + 格式” | 把模糊问题改成清楚问题 |
| 85-115 分钟 | 通用办公实操 | 演示写通知、改文案、做计划、整理纪要 | 跟着做 1-2 个练习 |
| 115-145 分钟 | 岗位场景实操 | 按部门/岗位做真实任务，比如销售、人事、行政、运营 | 用 AI 完成一个自己的任务 |
| 145-165 分钟 | 安全规范 | 哪些内容不能输入 AI，哪些结果必须人工检查 | 建立安全意识 |
| 165-175 分钟 | 分享复盘 | 请 2-3 位同事分享 AI 帮他完成了什么 | 看到真实效果 |
| 175-180 分钟 | 总结作业 | 布置课后作业：每天用 AI 完成 1 个工作任务 | 带着任务离开 |

## 三、你可以照着说的开场白

```
大家好，今天这场培训不是技术课，也不是让大家研究 AI 原理。

我们的目标很简单：让每个人今天至少学会三件事。

第一，能打开并登录一个 AI 工具。
第二，知道怎么向 AI 提一个清楚的问题。
第三，能把 AI 用到自己真实工作里，比如写通知、整理会议、做计划、写话术、总结资料。

今天主线工具是 ChatGPT。如果有人登录不上或者网络不稳定，也没关系，我们准备了 Kimi 和豆包作为备用工具。大家不用担心工具问题，我们不会让课程卡在安装和注册上。

我也是带大家一步一步练，不需要大家有技术基础。今天的标准不是你听懂了多少概念，而是你能不能现场用 AI 做出一个可用结果。
```

## 四、安装登录阶段控场话术

```
大家先跟着我的投屏来，不要自己跳步骤。

如果你的 ChatGPT 已经能打开，就继续跟着我操作。
如果你这里卡住超过 3 分钟，不要着急，也不要一直停在这里，先切到 Kimi 或豆包备用工具，保证你能跟上后面的练习。

今天我们学的是 AI 使用方法，不是比谁安装最快。
```

## 五、第一次提问练习

让所有学员输入：

```
请用 5 句话介绍你能如何帮助一名普通办公室员工提高工作效率。
```

然后继续追问：

```
请把上面的回答改得更口语、更容易理解，适合讲给完全没用过 AI 的同事听。
```

再追问：

```
请用表格列出 5 个最常见的办公场景，以及你分别能帮什么。
```

这一段的重点不是答案本身，而是让学员感受到：

1. AI 可以连续对话。
2. 第一版不好可以继续改。
3. 可以让 AI 改风格、改格式、改长短。

## 六、核心方法：AI 提问公式

告诉学员记住一句话：

```
角色 + 背景 + 目标 + 要求 + 输出格式
```

反面例子：

```
帮我写个通知。
```

好例子：

```
你是一名企业行政主管。

背景：公司下周五下午要组织一次 AI 入门培训，参加对象是销售部全员。

目标：请帮我写一条发到公司群里的培训通知。

要求：语气正式但不要太生硬，内容清楚，提醒大家带电脑。

输出格式：请用微信群通知的格式输出，控制在 200 字以内。
```

## 七、通用办公练习

### 练习 1：写通知

```
你是一名企业行政主管。

请帮我写一条内部通知。

背景：[填写]
通知对象：[填写]
希望对方做什么：[填写]
要求：简洁、清楚、有执行感。
输出格式：微信群通知。
```

### 练习 2：改文字

```
请帮我优化下面这段文字。

目标读者：[客户/老板/同事/员工]
希望风格：[专业/温和/简洁/有说服力]
要求：保留原意，不要夸张，不要官话。

原文：
[粘贴文字]
```

### 练习 3：做计划

```
你是一名项目管理顾问。

请帮我把下面目标拆成一份工作计划。

目标：[填写]
周期：[填写]
参与人员：[填写]

请输出：
1. 阶段划分
2. 每阶段任务
3. 负责人建议
4. 交付物
5. 风险提醒
```

### 练习 4：整理会议纪要

```
请把下面会议记录整理成会议纪要。

要求输出：
1. 会议主题
2. 关键结论
3. 已确认事项
4. 待解决问题
5. 下一步行动

原始记录：
[粘贴脱敏后的会议记录]
```

## 八、岗位场景练习

让每个人选择自己岗位里的一个真实任务。

可以这样引导：

```
现在请大家不要再用我的案例，换成你自己今天或这周真的要做的一件事。

比如：
销售可以写客户跟进话术。
人事可以写招聘 JD 或面试题。
行政可以写通知和会议安排。
运营可以写活动方案或复盘。
管理者可以写会议提纲或工作计划。

目标是：用 AI 帮你产出一个今天就能改一改拿去用的初稿。
```

岗位提示词：

```
你是一名[岗位专家]。

我的岗位是：[填写岗位]
我现在要完成的任务是：[填写任务]
背景是：[填写背景]
我希望达到的效果是：[填写目标]
要求：[填写语气、字数、格式、注意事项]

请先给我一个可用初稿。
```

## 九、安全规范

重点讲 5 条就够：

1. 不要输入客户或员工的身份证、手机号、住址、银行卡等敏感信息。
2. 不要上传未公开合同、报价、成本、利润率、财务数据。
3. 不要输入公司战略、未发布产品、内部决策材料。
4. AI 生成的报价、合同、政策、法律、财务内容不能直接使用。
5. 对外发送前必须人工检查，尤其是客户邮件、商务话术和正式通知。

讲师话术：

```
AI 可以帮我们提高效率，但不能替我们负责。凡是涉及客户、合同、金额、承诺、法律、财务、人事处罚的内容，都必须人工检查。
```

## 十、结尾总结

可以这样收尾：

```
今天大家不需要记住所有功能，只要记住一个核心方法：

以后遇到写作、总结、分析、计划、沟通、复盘类任务，先问自己一句：这件事能不能让 AI 帮我出一个初稿？

AI 不一定一次给出完美答案，但它可以帮我们更快开始、更快整理、更快优化。

课后作业很简单：接下来一周，每人每天至少用 AI 完成一个真实工作任务，并把好用的提示词保存下来。
```

课后作业：

1. 每人每天用 AI 完成 1 个真实工作任务。
2. 每人沉淀 3 条自己岗位上好用的提示词。
3. 一周后部门内部复盘：哪些场景最有价值，哪些提示词可以共享。

---

## 十一、给第一次讲师的提醒

1. 不用追求讲得很高级，第一次培训最重要的是让大家用起来。
2. 安装登录卡住时，不要慌，立刻切备用工具。
3. 不要把时间花在解释复杂概念上，多让学员动手。
4. 学员问你不会的问题，可以现场让 AI 一起回答。
5. 你不是来证明自己懂 AI 的，你是来带大家完成第一次 AI 使用体验的。
