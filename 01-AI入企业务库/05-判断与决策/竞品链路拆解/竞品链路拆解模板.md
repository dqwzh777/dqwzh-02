# 竞品链路拆解模板

📌 来源：作业四_判断力的建立.docx  
🎯 应用：从竞品忽略的空白里，找到自己的差异化切入口

---

## 拆解目标

竞品忽略的空白，往往是你的差异化切入口。

重点关注第 2 项「忽略了什么」：被竞品忽视的，常常是用户真正在乎但没有被满足的需求。

---

## 三维拆法

### 1. 讲什么卖点

内容里主推什么功能 / 场景 / 人群？关键词是什么？

### 2. 忽略了什么

用户其实在乎，但竞品没讲好 / 没讲的点是什么？

### 3. 用户为什么选他

评论区、问答区里，用户说的选择理由是什么？

## 差异化话术

把「忽略了什么」转成一句能说出口的差异化话术。

示范：竞品都没讲「夜间护理场景」→ 话术：「睡前 3 分钟，明早直接出门」

| 字段 | 内容 |
| --- | --- |
| 竞品共同忽略的点 |  |
| 用户真正关心的点 |  |
| 我的差异化话术 |  |
| 应该进入哪个知识库层级 | □ 判断层  □ 话术层  □ 场景层 |

---

## 可复用判断

- 当竞品都在讲同一个卖点时，我要检查：用户有没有更具体、更真实的使用场景没有被讲出来。
- 当竞品评论区反复出现某个选择理由时，我要判断：这是用户的购买按钮，还是只是事后合理化。
- 当竞品忽略了用户高频追问的问题时，我要优先把这个问题变成内容切入口。
