## 一、课程一句话总结

这是一套“以个人 IP 为流量入口，以内容换流量，以低价培训招募切片参与者，以分佣体系放大销售，再以供应链、自营品和私域沉淀利润”的商业模型；其底层思想是：目的优先、选择胜于蛮干、先复制后创新、用组织和利益机制放大个人能力，同时把现金流与风险控制放在规模和情怀之前。

## 二、课程结构拆解

### 1. 人生与创业的底层排序

讲者先区分了两类事情：

- “该做的事”：由儿子、丈夫、父亲、老板等社会角色产生的责任。
- “想做的事”：抛开社会角色后，作为个体真正想做的事。

他的排序是：先把该做的事做好，再去做想做的事。

贯穿全场的三条创业经验是：

1. 人之败者，非傲即惰——别懒、别狂。
2. 专注——一个阶段只集中精力做一件事。
3. 选行业的本质是选对手——不要只看市场大不大，要看自己能不能赢。

### 2. IP 的成长路径

讲者把 IP 成长分成四步：

1. 被看见：获得播放与曝光。
2. 被认可：获得点赞、正向反馈与价值观认同。
3. 被信任：用户相信你，开始产生交易。
4. 被依赖：用户持续回来，形成稳定变现与基础盘。

关键区分：

- 影响力是扩音器，只代表更多人听见你。
- 号召力才是商业资产，代表有人愿意相信并采取行动。
- 做到“被信任”可以变现；做到“被依赖”才可能稳定变现。

### 3. 自媒体的起点：先明确商业目的

开始做内容前，先回答四个问题：

1. 我来卖什么？
2. 我要卖给谁？
3. 因此，我该做什么内容？
4. 这些内容要做给谁看？

前两个是目的，后两个是过程与手段。讲者反复强调：做 IP 是为了完成商业目的，不是为了当网红；粉丝、播放、直播间人数都不是越多越好，关键是画像是否准确、能否进入商业闭环。

### 4. 博主与主播是两种职业

讲者认为：短视频博主和直播主播是两套不同的能力模型，除表达能力外重叠很少，不应期待一开始同时做好。

他的个人路径是：

- 先用长期销售、微商会议和约 680 场直播训练直播能力。
- 再训练短视频能力。
- 两年半内逐条推敲约 500 条短视频，通过“输入—整理—输出”反向训练认知。

可迁移结论：先集中练成一个核心技能，再扩展第二个技能。

### 5. 自媒体的三项前提

讲者把自媒体结果归因于：

- 天赋：表达力、镜头感、内容判断等基础能力。
- 运气：相同内容和环境也可能出现巨大流量差异。
- 心态：能承受数据波动、批评与无缘由的负面反馈。

他给出的测试方法是：选一个平台、一个账号，集中三个月验证，不同时铺多平台。如果三个月仍无有效信号，应复盘是否继续，而非无限死磕。

这一判断应视为讲者经验，不是普适的“三个月淘汰定律”。更合理的做法是提前定义验证指标：内容产量、完播、互动、有效线索、成交，而不只看粉丝数。

## 三、口播短视频生产 SOP

### 第 0 步：找对标

对标账号需同时满足：

- 产品相近：卖同类产品或服务。
- 人群相近：影响同一类目标客户。
- 账号做得好。
- 自己抄得了：制作成本、能力和资源可复制。

核心原则是“入行不创新”：新进入一个行业时，先学习成熟路径，理解规律后再创新。这里的“抄”应理解为拆结构、学方法和验证选题，不能照搬受版权保护的表达、脚本、画面或他人独创内容。

### 第 1 步：选确定性题目

优先找“低粉爆款”：账号粉丝基数不大，但单条内容获得明显超出账号基线的播放或点赞，说明题目和内容本身可能具备传播力。

选题来源：

- 每天持续观察同赛道内容，建立选题池。
- 使用平台热点与数据工具筛选低粉爆款。
- 从相关图文平台寻找已验证的议题，再改造成适合视频的表达。
- 只选择符合自己长期价值观的观点。

讲者建议每天刷同类内容 3 小时。学习时不必机械照搬时长，更重要的是建立固定的“观察—标注—归因—入库”流程。

### 第 2 步：建立素材号

讲者的方法是用独立账号持续向推荐系统反馈兴趣：

1. 搜索目标赛道关键词。
2. 对目标内容进行完播、点赞、收藏或评论。
3. 对无关内容选择“不感兴趣”。
4. 经过多轮训练后，利用推荐流持续获取同行内容。
5. 收藏或转发优质内容，形成自己的素材池。

本质不是“钻算法漏洞”，而是主动训练信息源，使素材采集更聚焦。

### 第 3 步：拆观点骨架

讲者以一条包含 8 个观点的视频为例：

- 从原内容中提炼 4 个观点，其中优先保留首尾两个观点。
- 从评论区热评提炼 2 个观点。
- 从同类热门内容补充 2 个观点。
- 最终按自己的价值观重新组织成 8 个观点。

首观点负责继续留人，尾观点负责强化记忆和关注转化。

更合规、更稳健的版本是：不要直接搬观点表述，而应记录“用户问题—核心冲突—证据—自己的判断”，再独立完成结构和表达。

### 第 4 步：设计钩子

钩子的本质是第一时间回答：“这条内容能给观众带来什么？”

错误开头：自我介绍、公司介绍、履历铺垫。  
有效开头：直接呈现利益、损失、冲突、结论或反常识。

讲者主张照搬爆款的第一句话和情绪。此做法存在抄袭、同质化及平台治理风险，不建议原样执行。应拆解其钩子机制，再用自己的事实和语言重写。

### 第 5 步：用自己的语言填内容

这一部分是整套内容方法中最重要、也最值得保留的原则：

- 用自己的能力水平和语言表达。
- 不伪装成另一个人。
- 用真实经历、真实判断和真实感受建立风格。
- 内容质量影响点赞，稳定风格和人格识别影响关注与信任。
- 不要让 AI 直接替代个人经历和判断；AI 更适合辅助整理、查漏、比较和改写。

讲者的表达是：“观众最后记住的，不是每句话，而是这个人给他的感受。”

### 第 6 步：数据复盘

讲者重点关注：

- 2 秒跳出：开头是否立即劝退。
- 5 秒完播：最初几秒是否提供足够价值或冲突。
- 后续完播与互动：观点密度和节奏是否有效。
- 关注转化：结尾是否让用户产生继续看这个人的动机。

复盘时不要只找“技巧”，而要定位漏斗中哪一环出了问题：选题、钩子、观点、证据、表达、节奏，还是人群不匹配。

## 四、直播三段式结构

### 第一段：快问快答，服务新粉

目标：用高信息密度留住新进入直播间的人。

准备方式：

- 整理行业高频问题库。
- 为每个问题准备简洁、有立场的回答。
- 通过反复练习提高反应速度。
- 新号阶段可持续约 30—60 分钟，根据数据调整。

讲者提到用“托”制造问题和互动。这涉及虚假互动、欺骗用户及平台违规风险，不应采用。可以使用预先征集的真实问题、主持人提问、公开问题卡或明确标注的模拟案例。

### 第二段：连麦或案例诊断，兼顾新老粉

目标：用真实案例和不确定性增加观看兴趣，并展示解决问题的能力。

执行要点：

- 有硬实力就解决真实问题。
- 提前积累观点、案例和备忘录，不把所有输出寄托于即兴。
- 针对可能出现的典型案例准备分析框架。
- 为后续切片预留清晰的冲突、结论和段落边界。

讲者公开讨论了剧本连麦和托。学习时应明确排除虚构真实用户、伪造效果与诱导成交等做法。

### 第三段：轻互动，维护老粉

目标：建立不以知识交换为唯一基础的人际连接，形成基础粉丝盘。

可采用：

- 复盘当天直播。
- 聊幕后过程、失败经历和生活片段。
- 回应老粉近况。
- 做无销售压力的轻互动。

讲者的核心判断是：“有意义的事多是价值交换，感情常在看似无意义的相处中积累。”其可取之处在于：真正的 IP 不仅提供功能价值，还要积累关系价值。

## 五、商业模式拆解

### 1. 基础闭环

整套模式可以浓缩为：

> 内容换流量 → 流量换代理/参与者 → 代理放大销量 → 销量增强供应链议价权 → 更好的产品和利润反哺内容与组织

讲者不把自己的主账号当作唯一收入来源，而是把它当作：

- 招募入口。
- 信任入口。
- 切片原材料生产端。
- 商品测试和内容测试场。

### 2. 低价训练营的作用

其 299 元切片训练营并非主要利润中心，而是参与者筛选和“岗前培训”入口。学员毕业后进入长期分佣体系，为 IP 生产和分发切片内容。

另有 99 元私域营销课程，用于吸引门槛更低、拥有零散时间、希望通过微信卖货的人进入私域供货体系。

低价课承担的商业功能：

- 降低加入门槛。
- 筛选有行动意愿的人。
- 覆盖部分交付成本。
- 把用户转化为渠道参与者。

这类模式必须特别关注代理层级、收益宣传、课程交付、消费者权益、传销边界和平台规则。

### 3. 组织结构与分佣

讲者描述的组织层级为：

- 学员：直接生产与销售。
- 教练：长期带学员。
- 教头：管理教练。
- 服务商：管理教头及区域或业务单元。

其公开示例：若可分佣金额为 100 元，直接销售人员约 40 元，教练约 17—18 元，教头约 7—8 元，服务商 5 元，剩余约 30 元用于税费和内部运营。原文前后数字略有出入，应以正式合同和财务模型为准。

背后的组织原则：

- 老板的核心任务是管人、理事、分钱。
- 责、权、利必须对应。
- 一个事项只设一个最终负责人，因为“责任除以二等于零”。
- 项目要同时给参与者“眼前有甜头、中间有赚头、长期有奔头”。
- 招募、训练新人、长期带队由不同角色承担。

### 4. 资产模型与流水模型

流水模型：本人持续开播、投流、卖货；一旦停工、流量涨价或封号，收入立即受影响。  
资产模型：积累多个分发账号、参与者、私域用户、供应链能力与自营产品，使收入不完全依赖单一账号或个人劳动。

讲者追求的核心资产是“渠道资产”，而不只是某个月的销售流水。

### 5. 产品演进：通货—联营—自营

产品供应链路径：

1. 用市场通货低成本测品。
2. 数据冒头后与品牌方联营。
3. 联营继续验证后开发自营品。
4. 用切片矩阵放大自营品。
5. 在私域根据已验证需求开发差异化版本。

这一模型的核心是先用真实销售数据验证需求，再把利润重心从带货佣金转向供应链和自营品。

### 6. 1.0—3.0 扩张路径

- 1.0：以单个 IP 跑通内容、代理、销量和供应链闭环。
- 2.0：把模型复制给其他知识类 IP，覆盖不同垂类。
- 3.0：把已验证的组织和分发模型复制到海外市场。

其中 2.0、3.0 在课程中主要属于规划与叙事，不等于已经完成验证。学习时应严格区分“已发生的数据”“近期计划”和“远期愿景”。

## 六、创业与经营方法论

### 1. 选行业：选对手，而不只选风口

反向判断两条线：

- 行业平均能力上限有多高？
- 行业最低道德下限有多低？

如果拼能力打不过上层，拼灰度又不愿意或不能和下层竞争，就不应轻易进入。

正向判断三条线：

- 自己是否热爱？
- 自己是否擅长？
- 是否有人愿意为这项能力买单？

结论：没有普遍最好的行业，只有与个人优势、资源和承受能力更匹配的行业。

### 2. 现金流优先级

讲者给出的创业排序是：

> 现金流 → 利润 → 规模 → 远景 → 情怀

他的风险观是：

- 现金流是抵抗风险的显性保障。
- 利润率是抵抗风险的隐性指标。
- 可以接受较低的利润额，但慎做低利润率生意。
- 尽量用买赠替代永久降价，避免不可逆的价格锚定。

### 3. 借钱只能“踩油门”，不能“造发动机”

讲者不建议在商业模型尚未验证时借钱创业。只有当产品、获客、交付、复购和安全边界已经跑通，借款才可用于放大已有模型，而不是用来寻找模型。

其个人复盘数据为：2004 年以来参与约 203—204 个项目，盈利比例约 9%—10%。该数据为讲者自述，未经外部核验，但所表达的风险意识值得保留：创业失败是常态，先确认自己赔得起。

### 4. 最小闭环试错

讲者最后给出的执行法：

- 最小代价，最快实施。
- 试错迭代，小步快跑。
- 少设计，多总结。
- 只要确认值得做且试错代价可控，就尽快开始。

机会不是等到完全想清楚才出现，而是在低成本行动中被试出来、碰出来。

## 七、案例与关键数据（均为讲者自述）

- 2023 年曾亏损约 4 亿元，并据此反思行业选择、傲慢和懒惰。
- 连续创业约 22 年，统计参与项目约 203—204 个，盈利比例约 9%—10%。
- 抖音主号约 712 万粉丝，视频号约 300 万粉丝。
- 国内切片矩阵总粉丝量约 1 亿。
- 切片体系约 1.7 万人、3.3 万个账号；公司发工资人员仅十几人。
- 2026 年 3 月起，体系单月销售额首次过亿元；主账号与直播间月销售额约数百万元，主要销量来自切片号。
- 自述切片体系每周新增约 2,000 人。
- 99 元私域课程单期进线数千人，平均转化率接近 50%，已运行到第七期、累计一万多人。
- 399 元知识产品包含 42 节短视频及一年 12 场小圈子直播；小圈子直播也承担商品二次转化。
- 自述某黄精产品约 12 个链接、单链接日销逾万单、总计约 20 万单/日。
- 粉丝画像自述：苹果用户约 42%，苹果与华为/荣耀合计逾 70%；广东、江苏、浙江、山东合计近 40%；25—45 岁占约 76%。

这些数字适合作为理解模式的案例，不应直接用于投资、合作或收益预测。需要合同、后台、财务、税务和第三方证据交叉验证。

## 八、6 要素提取

### A. 认知 / 观点

- IP 的价值不在粉丝数量，而在从被看见、被认可、被信任到被依赖的递进。
- 影响力只是扩音器，号召力才与商业结果直接相关。
- 做内容前先明确卖什么、卖给谁，再反推内容和受众。
- 新手应先复制已验证的结构，再形成自己的创新。
- 内容带来点赞，真实稳定的风格带来关注、信任和长期关系。
- 规模的前提不是老板亲自干更多，而是建立可复制的组织、分工和利益机制。
- 企业经营利润的本质之一是经营风险；现金流、利润率和去单点依赖比表面流水重要。

### B. 方法论

- IP 四阶段：被看见 → 被认可 → 被信任 → 被依赖。
- 商业四问：卖什么 → 卖给谁 → 做什么内容 → 做给谁看。
- 口播四步：确定性选题 → 钩子 → 观点骨架 → 个人化填充。
- 直播三段：快问快答 → 连麦/案例 → 轻互动维护老粉。
- 商业闭环：内容 → 流量 → 参与者/代理 → 销量 → 供应链 → 内容。
- 供应链升级：通货测品 → 联营 → 自营 → 私域差异化。
- 项目激励：眼前有甜头 → 中间有赚头 → 长期有奔头。
- 试错原则：最小代价、最快实施、小步快跑、少设计多总结。

## 九、批判性学习：哪些可用，哪些要谨慎

### 可直接借鉴

- 目的优先，用商业目标反推内容。
- 单点专注，先练成一种能力。
- 用低成本实验验证天赋、市场和模型。
- 建立对标库、选题库、问题库和案例库。
- 用自己的经历和语言形成风格。
- 预先准备直播内容，而不是完全依赖即兴。
- 把现金流、利润率和风险放在规模之前。
- 用供应链和渠道资产降低对单一账号的依赖。

### 需要验证后使用

- “每天刷 3 小时”“三个月不起号就放弃”等经验阈值。
- 课程中的粉丝、销量、转化率、团队规模与项目成功率数据。
- 灯牌、互动权重、账号健康分与限流之间的关系。
- 同公司平台之间算法逻辑相同、跨平台搬题重复率低等判断。
- 对房地产周期、银发经济及具体行业前景的判断。

### 不建议照搬

- 原样搬运爆款开头、配乐和表达。
- 用托、假连麦或虚构案例制造互动与成交。
- 以“法无禁止”为唯一伦理和合规标准。
- 通过多层代理、裂变和收益叙事模糊传销边界。
- 对性别、阶层等群体作刻板化表达。
- 把个人运气、气质和资源优势包装成人人可复制的确定性结果。

## 十、一页复习卡

### 记住 4 条主线

1. 人：专注、真实、大心脏，知道自己擅长什么。
2. 内容：卖什么、卖给谁；确定性选题、强开头、观点骨架、个人表达。
3. 组织：管人、理事、分钱；责权利一致；甜头、赚头、奔头。
4. 生意：内容换流量，流量沉淀渠道，渠道反哺供应链；现金流优先。

### 记住 4 个闭环

- 学习闭环：输入 → 整理 → 输出 → 复盘。
- 内容闭环：选题 → 钩子 → 观点 → 表达 → 数据。
- IP 闭环：看见 → 认可 → 信任 → 依赖。
- 商业闭环：内容 → 流量 → 成交/参与者 → 销量 → 供应链 → 复购与再传播。

### 最终行动原则

先判断方向是否值得做，再判断试错代价是否承受得起；如果代价可控，就尽快做出最小闭环，用真实数据迭代，而不是长期停留在设计和想象中。
