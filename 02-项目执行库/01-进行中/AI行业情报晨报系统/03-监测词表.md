## 八、实时异常组合

以下组合命中时提高扫描优先级：

- `[头部主体] + 发布/上线/开放/下架/涨价`
- `[应用名] + 访问量/下载量/排名 + 暴涨/下降`
- `[模型名] + API + 降价/免费/限流/停止`
- `[公司名] + 收购/融资/裁员/高管离职`
- `[AI 产品] + 数据泄露/诉讼/封禁/宕机`
- `[行业] + AI + 采购/中标/试点/规模化部署`
- `[政策机构] + 人工智能 + 办法/规定/标准/征求意见`
- `[海外热门应用] + 中国版/国内替代/同类产品`

## 十、排除词与降噪规则

默认降低以下内容优先级：

- 转载、汇总、盘点、回顾、旧闻、往期、合集
- 震惊、颠覆、史诗级、秒杀、遥遥领先、必看
- 纯课程招生、训练营、卖课、招商加盟、代理招募
- 无产品入口、无发布时间、无原始来源的截图
- 仅宣布“达成战略合作”但没有产品、金额或实施内容
- 同一新闻的媒体改写、公众号洗稿和短视频复述
- 单纯模型跑分但没有任务、成本和可复现条件

注意：排除词不是绝对删除。若同时命中官方来源、重大主体或异常信号，应进入人工复核。
