# 3-客户需求库

> 装什么：客户原话、聊天记录、评论区痛点、未成交原因、成交反馈
> 谁会读：选题挖掘、销售话术、内容方向 skill
> 真实场景：「老板心中卖点 vs 用户真实买点」

---

## 推荐文件结构

```
3-客户需求库/
├── README.md（本文件）
├── 客户原话集.md            ← 累计客户聊天里的金句、痛点、问题
├── 未成交记录.md            ← 谈崩的客户为什么不买
├── 成交反馈.md              ← 买了的客户最满意 / 最不满意什么
└── 评论区痛点.md            ← 公众号 / 小红书评论里的痛点
```

## 怎么填

### 客户原话集.md

每条原话保留原汁原味,**不要美化**——这是最珍贵的内容素材。

```markdown
## 2026-XX-XX | 客户 A（背景：女,35 岁,做美业）

> "我每天加 50 个新好友,但一个月成交不了 5 个,是不是引流出问题了?"

提取标签：#引流过剩 #转化痛点 #美业
```

### 未成交记录.md

每个未成交客户记一下**为什么没买**——这是产品调整的根。

```markdown
## 客户 B（2026-XX-XX）
- 背景：
- 卡点：觉得「不需要现在买」
- 反思：是产品价值没讲透,还是时机问题?
```

---

## 上手第一步

复制最近一周的**5 段最有信息量的客户聊天记录**到 `客户原话集.md`,先有素材再谈结构。
