# 6-内容生产库

> 装什么：① 选题（待写的内容方向）② 成稿（写好的内容）——这个库是内容流水线的工作区。
> 谁会读：内容生产 skill（写之前翻选题，写完把成稿归这）
> 真实场景：「写之前不发愁选题，库里有 30+ 待选；写完的稿子也沉淀下来，下次能复用」

---

## 推荐文件结构

选题、成稿分开放，每个一个文件，方便 AI 精准调用。

```
6-内容生产/
├── README.md（本文件）
├── 选题/
│   ├── 选题-XX怎么做.md
│   └── 选题-XX是什么.md
├── 成稿/
│   └── （写好的内容放这）
└── 已归档/
    └── （已发布的选题 / 成稿搬这里，不删除）
```

## 每个选题建议格式

```markdown
# [选题标题]

> 来源：XX录音 / 客户 XX 问的 / 自己想到的
> 创建日期：YYYY-MM-DD
> 适合平台：朋友圈 / 小红书 / 公众号 / 口播

## 写作方向

[2-3 句话描述怎么写、切入角度]

## 核心观点

- 论点 1
- 论点 2
- 论点 3

## 可用素材

- 案例：来自素材案例库的 XX
- 客户原话：来自客户需求库的 XX
- 方法论：来自方法论库的 XX

## 标题候选

- 
- 
- 
```

---

## 文件命名建议

选题阶段：**直接用标题，无前缀**，方便扫一眼就知道写什么。

例：
- `选题-AI 让普通人能做老板了吗.md`
- `选题-为什么大部分老板搞不定 AI.md`

发布后归档：加日期 + 平台前缀，移到 `已归档/`，例：
- `已归档/20260606-公众号-AI 让普通人能做老板了吗.md`

---

## 上手第一步

**不用主动填**——把「录音处理」skill 跑起来，以后每段录音里识别出的可发展选题，AI 会自动入库；写完的内容也会归到「成稿」。

如果手痒想先填，就把你**最近 3 个想写但没写**的选题各开一个文件。
