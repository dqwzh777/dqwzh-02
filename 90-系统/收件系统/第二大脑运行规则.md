# 第二大脑运行规则

## 一条主链

```text
电脑或AI产生资料
→ 高可信自动收件 / 低可信待确认
→ 保留原件与来源
→ 生成可搜索资料页
→ 每周提炼知识候选
→ 项目或案例验证
→ SOP与Skill
→ 任意AI按AI读取说明调用
```

## 三种东西不能混

1. **原始资料**：证明“原文或文件是什么”，放在资料源。
2. **可复用知识**：回答“以后遇到类似问题怎样判断”，放在知识层。
3. **长期事实**：关于个人与业务的已确认事实，只由个人与业务主档案承载。

每日复盘是变化日志，Codex长期记忆是压缩执行版，两者都不能取代主档案。

## 资料怎样进入

- 主动投递：放入 `/Users/mac/Documents/知识库投递/`，下一次每日总管自动处理。
- 自动发现：滚动扫描 Desktop、Documents、Downloads，只把高可信成品自动收件。
- 低可信：只登记来源并等待确认，避免把下载垃圾、临时稿和无关文件塞满知识库。
- 大文件：视频与超过100MB资料只登记，不复制，防止Vault和Git膨胀。

## 可搜索性的真实边界

- 已支持全文提取：Markdown、TXT、CSV、Word、PDF、PPT、Excel。
- 图片由macOS Vision本地OCR；音频由本地Whisper small转写并生成分段时间轴；两类结果都必须人工复核。
- 旧版 Office 格式只保存元数据，转换后才能进入全文检索。
- 每个提取页必须保留原附件链接、电脑来源路径、处理状态和“资料观点不等于个人观点”的边界。

## 自动化节奏

| 周期 | 自动执行 | 不自动执行 |
| --- | --- | --- |
| 每天22:20 | macOS后台收件、去重、文本提取、OCR、转写、运行报告 | 语义提炼、升级长期事实、删除文件 |
| 每天22:30 | Codex核对后台结果、当天AI沟通复盘、安全Git同步 | 未复核内容升级为事实、强推Git |
| 每周日 | 六要素提炼、链接来源、列出积压 | 猜测未转写内容、安装Skill |
| 每月1日 | Git、断链、重复、积压、可达性体检 | 自动移动或批量清理 |

机械处理由macOS LaunchAgent独立运行；语义处理、周/月治理和GitHub同步由一条“个人第二大脑每日总管”按日期条件执行。即使Codex当晚失败，原始资料仍会收件并留下失败状态；下次总管会尝试恢复。

管线源代码、OCR脚本、LaunchAgent配置和依赖清单均随Vault和GitHub保存；运行副本部署在 Codex Skill 与用户LaunchAgents中，恢复或升级时必须做一致性核验。

## 人工只需要做三件事

1. 想明确入库的资料放进 `知识库投递`。
2. 在[[00-知识库入口/待整理资料|待整理资料]]处理“待确认、待转写、待OCR”。
3. 对长期记忆候选、已验证知识和待安装Skill作最终确认。

## 验收标准

- 人从知识库总览三步内能到达目标内容。
- AI能从资料页检索正文，并追溯到原件和来源。
- 未处理音频和图片不会被误报为已读。
- 资料、知识、项目证据、SOP之间保留链接。
- 自动运行失败能从状态时间、队列和任务回执被发现。
