# 收件系统说明

## 人看到的入口

日常只看[[00-知识库入口/待整理资料|待整理资料]]。日期收件记录、状态JSON和运行细节留在本目录后台，不占据知识库首页。

## 监控范围

- Markdown、TXT和逐字稿。
- Word、PDF、PPT、Excel和CSV。
- JPG、PNG、WEBP等图片。
- MP3、M4A、WAV、AAC等音频。
- MP4、MOV等视频只登记线索；大文件存储方式另行确认。

## 处理链路

```text
发现新增资料
→ 按上次成功运行时间滚动扫描
→ 去重和保留原件
→ 登记到待整理资料
→ 转写/OCR/文本提取
→ 进入资料源
→ 提炼知识
→ 项目验证
→ SOP或Skill
```
