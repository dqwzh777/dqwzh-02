# 对标表达拆解与迁移

> 用途:拆解同行/标杆为什么让人愿意看、愿意信、愿意咨询,再迁移成自己的业务表达。
> 核心:学结构、学判断、学证据摆法,不洗稿、不照搬。

## 一飞版说明

这个 skill 面向老板/IP/企业的真实表达训练。对标材料可以是短视频、直播间话术、课程开场、销售页、私域文案、成交案例,重点是拆清楚"为什么让人愿意信"。

## 这个 skill 做三件事

1. **拆表达**:它第一句话怎么抓人,中间怎么推进,最后怎么承接。
2. **拆信任**:它用了什么身份、案例、数据、场景和结果让人相信。
3. **做迁移**:把结构迁移到你的产品、客户、案例和方法论里。

## 对标材料类型

| 对标材料 | 重点拆什么 |
|---|---|
| 短视频/口播 | 第一口、节奏、转场、收束句 |
| 图文/文章 | 标题、段落推进、观点密度 |
| 课程开场 | 定调、故事、学员动机、信任建立 |
| 销售页/海报 | 价值承诺、适合人群、证据、行动入口 |
| 私域话术 | 异议处理、语气、下一步推动 |
| 直播/公开课 | 现场互动、问题设计、成交铺垫 |

## 拆解维度

```markdown
## 对标拆解

- 对标来源:
- 适合学习的地方:
- 不适合照搬的地方:

### 1. 人群
它在对谁说话?

### 2. 第一口
第一句话解决什么注意力问题?

### 3. 推进结构
它按什么顺序让人继续看?

### 4. 信任证据
用了哪些身份、案例、数据、现场、细节?

### 5. 情绪与身份
让用户产生了什么感受:被理解、被提醒、被戳中、想咨询?

### 6. 转化入口
最后把用户带向哪里:评论、私信、课程、咨询、成交?
```

## 迁移前先读六库

| 迁移要素 | 先读 |
|---|---|
| 你的身份、风格、禁区 | **老板与企业说明书** |
| 要承接的产品/服务 | **产品服务库** |
| 客户真实问题和原话 | **客户问题库** |
| 你的案例和信任证据 | **案例证据库** |
| 你的框架和判断 | **方法SOP库** |

---

## 迁移原则

- **复用结构,不复用文字**。
- **复用表达机制,不复用人设**。
- **先问适不适合你的业务,再问能不能写得像**。
- **必须换成你的客户问题、你的案例、你的产品承接**。
- **如果没有证据,只能输出待补资料,不能编案例**。

## 课堂讲法

这节课不要讲"照搬爆款",要讲:

> 对标不是抄答案,是看别人怎么建立信任,再换成你的业务证据。

课堂练习:给学员一条同行内容,先拆"第一口、信任证据、转化入口",再要求他用自己的客户问题和案例重搭一版。
