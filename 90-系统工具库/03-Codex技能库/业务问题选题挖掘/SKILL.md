# 业务问题选题挖掘

> 用途:从真实业务现场里挖出值得写、值得讲、值得做成销售话术的选题。
> 核心:不追热点,先看客户反复问什么、现场反复卡什么、成交反复差在哪。

## 选题来源

优先从这些地方挖,不要只从平台热榜挖:

1. **客户问题**:私聊、咨询、评论区、直播间提问、线下课提问。
2. **客诉/差评/吐槽**:不满意、没听懂、不会用、觉得贵、觉得麻烦。
3. **销售卡点**:客户为什么不买、为什么犹豫、为什么比价。
4. **业务现场**:门店、工厂、办公室、交付现场、团队会议。
5. **案例复盘**:客户前后变化、过程细节、失败教训、关键动作。
6. **对标表达**:同行怎么讲,客户为什么会被他吸引。

## 判断一个选题值不值得做

### 1. 是否是真问题

- 是否反复出现?
- 是否影响成交、信任、交付或团队效率?
- 客户是否愿意花时间、花钱或承担成本解决?

### 2. 是否适合你讲

- 是否和你的定位、产品、服务有关?
- 你是否有真实判断、案例或现场经验?
- 讲完能不能自然承接到你的业务,而不是只赚一个赞?

### 3. 是否有证据

- 有没有客户原话?
- 有没有截图、录音、案例、过程记录?
- 有没有能支撑观点的结果或细节?

### 4. 是否能转化成动作

| 选题类型 | 应用 |
|---|---|
| 信任型 | 让客户相信你见过真实问题 |
| 教育型 | 让客户理解为什么要这样做 |
| 转化型 | 处理异议、解释价格、推动咨询 |
| 诊断型 | 帮学员/客户看见自己的问题 |
| 产品型 | 反推产品优化、服务边界和交付标准 |

## 课堂讲法

这节课不要讲成"怎么蹭热点",要讲成:

> 老板每天听到的问题,就是公司最值钱的内容原料。

让学员现场拿 3 条客户原话练习:先标来源、应用、状态、缺口,再判断它能变成内容、话术、案例还是产品优化。
