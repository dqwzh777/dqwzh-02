## 核心:先读库,再写

| 写什么 | 先读 |
|------|------|
| 任何文章（必读） | **老板与企业说明书**——你的定位、写作风格、禁区 |

## 基础写作方法:角度 → 框架 → 确认 → 正文

**写正文不要一步到位,分四步:**

1. **角度自检**——先想"所有人都会从什么方向写这个选题?"。如果你的角度就是大众第一直觉,换一个（找那个合情合理、但别人想不到的角度）。这一步权重最高,角度不对后面全白费
2. **出框架**——标题 2-3 个候选 + 开头钩子 + 主体段落推进 + 结尾。**先只给框架,不写正文**,问一句"框架 OK 吗?"
3. **等确认**——用户说"可以写"再动笔
4. **写正文**——基于确认的框架,读素材库,写完整初稿（不留占位）

> 更深的写作方法（写作风格 DNA、找角度技巧、情绪路径、对标作者结构等），沉淀进你自己的方法SOP库,写之前读取。

## 流程:从选题到公众号

1. **选选题**——从内容与承接库（选题库）选一个,或用户直接给话题
2. **读对应的库**（见上表）
3. **走"角度→框架→确认→正文"**写出文章
4. **保存**——存到你的待发布目录,命名 `YYYYMMDD-公众号-关键词-v1.md`;如果是从选题库选的,写完把原选题文件清理掉,不留残留

---

## 公众号合规红线（三条铁律）

1. **不写具体收入数字**（月入 X 万）→ 用"收入还不错""副业超过主业"
2. **不写"轻松赚钱""躺赚""普通人也能"** → 用"需要持续投入"
3. **不在文章里直接放付费转化路径**（加微信、私域、收入截图）→ 文末"评论区聊"
