| 写什么 | 先读 |

## 基础写法

- **像朋友聊天**,不教育人,用"我"的视角(朋友圈里不自称名字)
- **一条只讲一件事**:一个案例 + 一个观点 + 一个情绪就够
- **段落极短**,段与段之间空行(朋友圈要空行才好读,和公众号不同)
- **具体数字 > 形容词**;客户 / 学员案例脱敏("有个客户""一个朋友")
- **自嘲 / 自黑是信任加速器**
- **合规**:不写具体收入数字;不写"轻松赚钱""人人都能";不硬导流

> 更深的写作风格(你自己的几种文案风格 DNA),建议你用历史朋友圈反向提炼,沉淀进自己的方法SOP库,写之前一并读取。

---

## 流程

1. **确定写什么**——一个观点 / 一件事 / 一个案例 / 一个感悟
2. **读对应的库**(见上表)
3. **写**——100-800 字,一条只讲一件事

## 课后选修:反向挖出你自己的风格

通用版写出来还差点"你的味道"。想让 AI 写得**真正像你**,用你的历史内容反向挖一次风格——

把你过往 30-50 篇朋友圈 / 小红书 / 公众号粘进一个文件,发给 AI:

```
请扫描这份"我的历史内容",做 4 件事:
1. 不看主题,只看写作风格(句式 / 节奏 / 用词 / 开头结尾 / 信息密度),聚成几种独立风格
2. 每种起一个有画面感的名字(如"高信息密度条目体""碎碎念反思体")
3. 每种风格写一份 references 文件,存进本 skill 的 references/
   (内容:DNA 特征 + 从历史内容挑 3-5 篇示例 + 开头/结尾模板 + 常见陷阱)
4. 给一份"场景 → 风格"映射表,告诉我什么素材走哪种风格

我的历史内容:[粘贴]
```

挖完后,本 skill 就能按你的风格写——以后说"写 XX 话题朋友圈",AI 自己挑对应风格,写出来就是你的味道。

## 质量自检

- 观点清晰吗?能用一句话说清核心吗?
- 有具体案例 / 数字支撑吗?不是空洞的道理?
- 像你说的话,还是 AI 腔?
- 一条只讲了一件事吗?没贪多?
- 合规吗?中文标点对吗?
