# Knowledge-base linking pattern

Use this pattern when the user wants an Obsidian knowledge base or asks to connect new notes with old notes.

## Stable hubs
- `0-使用说明老板画像速览`
- `老板个人画像与协作要求-重建版`
- `执行准则`
- `角色画像`

## Linking rule
- Link every new hub note to the older structural pages.
- Link older structural pages back to the new hub note.
- Also link the six core vault modules:
  - `2-产品库/README`
  - `3-客户需求库/README`
  - `4-素材案例库/README`
  - `5-方法论库/README`
  - `6-内容生产/README`

## Hygiene
- Remove duplicate `## 相关链接` headings when patching pages.
- Prefer a compact link list over a long prose paragraph.
- Verify the graph by reading the files back after edits.
