# Second-brain scaffold

Recommended starter pages:
- `第二大脑.md` — index/home page
- `收集箱.md` — inbox for unprocessed ideas
- `项目.md` — active/planned work
- `笔记.md` — reusable knowledge and methods
- `资料.md` — references, links, media
- `待办.md` — actionable items
- `回顾.md` — daily/weekly/monthly reflection

Common workflow:
1. Create the index page first.
2. Create the six child pages as linked notes.
3. Keep each page short and category-focused.
4. Reuse the same structure for future vaults.
