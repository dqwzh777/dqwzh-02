# 博派AI＋TOKENIC：长对话、访谈与即兴思考研究

> 调研日期：2026-07-12。排除知乎、微信公众号、百度百科。结论先行：公开可检索到的完整长访谈很少，本维度主要由公开演讲/发布会课件、活动问答语境和课程介绍补足；不能伪装成“完整访谈语料”。

## 1. 已找到的长对话/演讲型来源

### 1.1 小七姐《智能体设计指南》新书发布会（2025-03-29）

- **形式**：发布会演讲课件/内容摘录，不是逐字访谈。
- **关键观点**：人工智能时代，表达不仅是沟通，也是与模型“共同创造”；提示词认知从清晰表达进入结构化表达，熟练后又回到简洁；进阶分叉为探索语言上限，以及可复用框架、智能体工程与产品思维。
- **即兴思考特征**：用“语言游乐场”而非纯工程隐喻，把对话分成确定性产出、过程价值、混合价值。她重视对话本身带来的概念澄清和意外洞见，而非只把模型当代写工具。
- **例子选择**：研究方法课程、医患沟通训练等复杂场景，常先把任务拆成内容数量、评价标准、结构格式，再加入尊重、准确等价值约束。这表明她习惯把软目标翻译成可检查结构。
- 来源：[发布会课件转存页](https://www.fxbaogao.com/detail/4804100)，日期2025-03-29；**一手内容的第三方转存，中高可信**。缺少原视频/完整逐字稿，不能分析追问、停顿与立场变化。

### 1.2 冯博 Startup Grind 深圳“零基础AI提效工作坊”（约2024）

- **形式**：公开活动介绍与现场Q&A预告，不是会后逐字稿。
- **对话场景**：面向精益创业者，把演讲按AI提效、AI创新、AI创业、Q&A组织；案例链路覆盖营销—客服—SaaS—企业知识库，并安排现场选择一个节点实操。
- **思考特征**：先给具体业务链，再让参与者动手验证；把“一人公司”作为AI改变组织边界的主要叙事。
- 来源：[活动行页面](https://3025039603765.huodongxing.com/event/1772777976011?layout=EN&qd=5428363092855)，约2024；**主办方二手，中可信**。未找到完整录像或问答记录，不能声称知道他被追问时如何回应。

### 1.3 冯博企业课程/现场教学资料（约2025）

- **形式**：讲师及课程介绍，不是独立媒体访谈。
- **互动方式线索**：强调亲自进入客户公司考察/短期上班，再根据业务定制工作流；现场教学和演示围绕办公、营销、人力、开发等场景。这提示其回答问题倾向于追问业务背景、找流程节点、现场做出交付物。
- **常用类比/框架**：“AI超级员工”“1人就是1个队伍”把技术能力映射到组织角色；比讨论模型参数更便于管理者理解。
- 来源：[大数跨境课程介绍](https://www.10100.com/article/31884430)，约2025；[名课堂课程页](https://resource.mingketang.com/houseCourse/desc?id=41865)，核验2026-07-12；**二手，中可信，营销材料属性强**。

## 2. 从对话型材料可谨慎提炼的反应模式

### 博派AI / 冯博

1. **遇到抽象AI问题，拉回业务链路**：从营销、客服、知识库等流程节点回答，而不是停在趋势判断。证据：活动议程与课程案例；中可信。
2. **用角色隐喻降低理解门槛**：称Agent为“超级员工”，称个体增强为“1人就是1个队伍”。证据：多门课程标题重复；中高可信。
3. **偏好现场实操而非长篇概念讲授**：活动设置节点实操，官网强调少PPT、多产出。证据：一手官网+主办方资料；高可信。
4. **可能先追问上下文和验收指标**：由 BOBO-321 的 Background 与“场景×交付物×验收”推断。属于**方法论推断**，不是访谈行为实录；中可信。

### TOKENIC / 小七姐及团队

1. **把问题转成结构化约束**：数量、角色、流程、格式、质量标准一起定义。证据：发布会课件案例；中高可信。
2. **同时承认结果价值与过程价值**：对话可产出文档，也可用于思考、碰撞、澄清。证据：发布会课件；中高可信。
3. **成熟后追求简洁，而非永远堆结构**：新手借结构获得稳定性，进阶者回到短而精准的表达。证据：发布会课件；中高可信。
4. **组织层面先调研再设计**：高管、部门、一线访谈后才评估数据和流程。证据：TOKENIC官网；高可信，但属于标准服务流程而非个人临场反应。
