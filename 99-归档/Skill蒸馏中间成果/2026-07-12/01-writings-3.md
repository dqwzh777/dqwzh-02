## 1. 博派AI的著作与系统化表达

### 1.1 《务实理解ChatGPT指南》

- 多个讲师/活动介绍称冯博著有《务实理解ChatGPT指南》，但本轮未找到出版社、ISBN、正式书目页或作者公开全文。因此可以确认“该标题被持续用于冯博履历”，但不能确认它是正式出版物、内部讲义还是电子指南。
- 标题本身及其后续课程体系显示稳定倾向：重“务实理解”和业务使用，而非模型理论。
- 来源：[Startup Grind 深圳活动页](https://3025039603765.huodongxing.com/event/1772777976011?layout=EN&qd=5428363092855)，约2024；[名课堂讲师页](https://resource.mingketang.com/houseCourse/desc?id=41865)，核验2026-07-12；均为**二手，中可信**。书的性质与内容为**未核验**。

### 1.2 BOBO-321：当前最完整的一手“系统长文”

- B-O-B-O 分别为 Background（背景）、Oral（口述）、Boundary（边界）、Operate（执行）；321 为精通3款工具、定制2款技能、重构1个体系。
- 其内在逻辑不是“提示词技巧合集”，而是：先补上下文 → 用口述降低表达摩擦 → 把人的判断固化为边界 → 让AI执行、人复核 → 最后形成少工具、可维护的系统。
- 反复出现的交付准则是“场景 × 交付物 × 验收”，以及以 ROI（投资回报率）、模板、流程、持续使用情况衡量培训效果。
- 来源：[博派AI官网](https://www.bopai.online/)；©2026；**一手，高可信**。

### 1.3 课程体系作为系统思想证据

- 冯博课程标题从办公、营销、人力、开发到智能体，均使用“AI超级员工”母题，说明其基本单位不是单个工具，而是可以承担岗位流程的AI能力组合。
- “从云原生到AI原生开发”“1人就是1个队伍”“新质生产力引擎”等表达，把AI定位为组织与生产流程重构工具。
- 案例描述强调先到客户现场理解业务，再从营销、客服、SaaS、知识库串成工作流；这是“业务先于技术”的稳定主张。
- 来源：[名课堂课程页](https://resource.mingketang.com/houseCourse/desc?id=41865)，核验2026-07-12；[大数跨境课程介绍](https://www.10100.com/article/31884430)，约2025；**二手，中可信**（内容可能由讲师/机构供稿，营销属性强）。

## 2. TOKENIC的著作与系统化表达

### 2.1 《智能体设计指南：成为提示词高手和AI Agent设计师》

- 书目核验：云中江树、王照华（甲木）、伊丽琦（小七姐）、李继刚著，机械工业出版社，2025-03，ISBN 978-7-111-77584-3，约410/412页。
- 结构：第一部分为提示词基础、六种常用方法与结构化提示词；第二部分为智能体概念、原理、设计模式、平台、提示词/插件/知识库/记忆/工作流等组件、单/多智能体、局限及缓解。
- 对 TOKENIC 蒸馏最有价值的共识：提示词不是咒语，而是表达和工程化接口；Agent设计要从任务目标、组件、工作流和局限整体考虑；理论最终必须落到可运行案例。
- 来源：[新华书店商品书目](https://item.xhsd.com/items/110000104706690)，出版时间2025-03-01；[兰州理工大学图书馆书目](https://opaclib.lut.edu.cn/opac/book/dec0833d4b99e209be2910ccee1e7ce5)；均为**权威书目二手，高可信**。可读章节：[掌阅电子书](https://s.zhangyue.com/read?anchorId=&appId=5ce699f0&bid=13361447&cid=22&rentId=101896)，**一手文本节选，高可信**。

### 2.2 小七姐的提示词知识库

- WaytoAGI知识库汇集小七姐的提示词教程与智能体案例，身份介绍为长期互联网产品经理、AIGC课程编写者和重度实践者。
- 这类写作的显著方法是“喂饭级”：把抽象提示方法拆成新手可执行步骤，并要求联网验证、角色/任务约束和输出格式。
- 来源：[WaytoAGI 小七姐提示词知识库](https://articles.waytoagi.com/docs/XnBqwKxoDicGvikWL0lcB4yEnth)，核验2026-07-12；**一手/社区官方汇编，中高可信**（具体页面作者署名需逐篇复核）。

### 2.3 TOKENIC官网的方法论长文

- 咨询流程固定为：深度调研 → 数据评估 → 流程分析 → AI机会评估 → 战略规划。这比“先选模型/工具”多了组织诊断与投资优先级判断。
- 核心价值句“产品力大于影响力”“不做PPT咨询”“以可量化业务成果为交付标准”，体现强烈的反空谈与结果导向。
- Roome 的“房间 + 角色”架构把上下文与记忆作为产品级基础设施，而非每次临时补提示词。
- 来源：[TOKENIC官网](https://tokenic.cn/)；核验2026-07-12；**一手，高可信**。其中150+场、5000+学员、120+企业及案例提效数字是**组织自述，未独立审计**。

## 3. 跨来源反复出现的“真信念”候选

1. **AI价值必须进入真实工作流**：两家官网、冯博课程和《智能体设计指南》均重复出现。高可信。
2. **上下文、知识库、记忆和边界比花哨工具更重要**：BOBO-321 与 Agent组件设计互相印证。高可信。
3. **人机协同不是完全无人化**：博派明确“人放复核位，AI放产出位”；TOKENIC强调调研、设计、迭代和陪跑。高可信。
4. **交付应可量化、可复用、可验收**：双方官网高频出现。高可信，但具体案例数字需第三方核验。
5. **从表达技巧走向工程与产品**：小七姐新书发布课件明确描述“结构化表达 → 简洁表达 → 可复用框架/工程化/产品思维”的进阶路径。来源见02文件，可信度中高。

## 4. 矛盾与证据缺口

- 博派官网称冯博“前美股上市公司创始成员”，活动页更具体称“趣店CEO助理及敲钟团成员”；“创始成员”与“CEO助理/敲钟团成员”不是同义词，暂不合并，待公司档案或当事人履历核验。
- 名课堂称冯博“腾讯工程师”，活动页与官网未重复这一经历；只能列为第三方履历声称。
- 博派官网称“微软全球首批AI工程师”，活动页称“全球首批微软AI工程师认证”；认证具体名称、批次和颁发时间未找到微软官方证明。
- TOKENIC官网把小七姐列为《智能体设计指南》作者，正式书目显示实名伊丽琦，可合理对应，但仍应在最终Skill中写作“伊丽琦（笔名小七姐）”。
- 两家官网均有大量客户数、满意度、效率提升数字；没有公开审计方法、样本与基线，适合用于理解其自我定位，不宜作为客观绩效结论。
